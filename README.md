We build a local research tool that makes public observations inspectable.

**Atlas Beta 1.1** brings asynchronous source checks, typed relationship graphs, an evidence inspector, offline report import, and a Python API together in one local workspace.

- **Evidence before assumptions.** A username match is a lead, not an identity verdict.
- **Useful without API keys.** Public endpoints and local metadata, with explicit limits.
- **Honest about uncertainty.** Unavailable sources stay unavailable; errors do not become negative matches.
- **Built to connect.** JSON reports, REST, OpenAPI, and an async Python SDK.

Python 3.11+ · FastAPI · asyncio · MIT

**Status:** active beta. Source availability varies. Persistent cases and timeline are on the roadmap.

Start with the [offline demo](https://github.com/atlas-osint/atlas#try-it-in-two-minutes), review the [source coverage](https://github.com/atlas-osint/atlas#source-coverage), or [contribute a tested provider](https://github.com/atlas-osint/atlas/blob/main/CONTRIBUTING.md).
